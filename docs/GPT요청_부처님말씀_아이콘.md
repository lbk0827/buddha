# GPT 요청 — 「부처님 말씀」 카드 아이콘

절 탭 「부처님 말씀」 카드 왼쪽에 작은 그림 하나를 둔다. 카드 글자 왼쪽, 지름 약 40dp.

## 왜 연꽃인가

| 후보 | 좋은 점 | 걸리는 점 |
|---|---|---|
| **연꽃 (추천)** | 불교를 가장 넓게 대표하고, 누구나 한눈에 안다. 부처님이 서 있는 연꽃 대좌와 같은 꽃이라 화면 안에서 이어진다. 작게 줄여도 모양이 무너지지 않는다 | 「말씀」과의 직접 연결은 약하다 |
| 법륜(수레바퀴) | 「법(말씀)을 굴린다」는 뜻이라 의미로는 가장 정확하다 | 40dp로 줄이면 배의 조타륜처럼 읽힌다. 처음 보는 사람은 모른다 |
| 경전 두루마리 | 「말씀」을 글자 그대로 보여 준다 | 일반 문서·메모 아이콘처럼 보여 불교 느낌이 약하다 |
| 염주·목탁 | 앱 안에 이미 있는 물건 | 놀이 탭(목탁)·증표(염주)와 겹쳐 어디로 가는 버튼인지 헷갈린다 |
| 🪷 이모지 | 리소스가 필요 없다 | 기기마다 모양·색이 달라 부처님 그림과 화풍이 맞지 않는다 |

## 받을 것

| 저장 파일 | 내용 |
|---|---|
| `Imgs/icon_lotus.png` | 반쯤 핀 연꽃 한 송이 |

같은 이름이 이미 있으면 덮어쓰지 말고 `_v2`처럼 번호를 붙인다.

## 그림 조건

- **화풍**: `Imgs/base_saffron.png`(부처님)와 `Imgs/seat_lotus.png`(연꽃 대좌)와 같은 세계. 부드러운 3D, 매끈하고 둥근 형태, 과한 디테일 없이.
- **색**: 연꽃 대좌와 같은 연분홍 꽃잎, 꽃잎 끝으로 갈수록 조금 진한 분홍. 줄기·잎은 넣지 않거나, 넣더라도 꽃 아래 작은 잎 하나까지만.
- **모양**: 정면에서 살짝 위에서 본 반쯤 핀 꽃 한 송이. 꽃잎 5~7장. **40dp로 줄여도 연꽃으로 읽히게** 윤곽이 단순하고 또렷해야 한다.
- **조명**: 왼쪽 위에서 오는 부드러운 빛 하나.
- **배경**: 밝은 카드(흰색 `#FFFFFF`)와 어두운 카드(`#221F1A`) 위에 놓인다. 두 곳 모두에서 윤곽이 보여야 한다.

### 피할 것

- 글자, 만(卍) 같은 기호, 부처님 얼굴이나 사람
- 물방울, 반짝이, 빛줄기 같은 장식
- 물 위에 떠 있는 장면, 연못, 배경
- 그림자, 테두리

## 출력

- 정사각형 1024×1024, 꽃이 가운데, 사방에 여백 10% 이상.
- 배경은 **투명(알파 채널)**. 안 되면 순수 마젠타 `#FF00FF`. 회색 체크무늬를 그려 넣는 건 투명이 아니다.
- 반투명 부분 없이 불투명하게.
