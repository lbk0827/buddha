# 목탁 이미지 작업 지시서

「놀이」 탭의 목탁을 그림으로 바꾼다. 지금은 코드로 원과 틈을 그린 것이라(`MoktakPainter`) 부처님 캐릭터와 결이 맞지 않는다.

받을 것은 **두 장**이다. 몸통과 채를 따로 받아야 앱에서 채가 목탁을 내리치는 움직임을 만들 수 있다.

| # | 저장 파일 | 내용 |
|---|---|---|
| 1 | `Imgs/moktak_body.png` | 목탁 몸통 (손잡이 포함) |
| 2 | `Imgs/moktak_mallet.png` | 목탁채 |

같은 이름이 이미 있으면 덮어쓰지 말고 `_v2`처럼 번호를 붙인다.

## 1. 어디에 어떻게 쓰이나

- 놀이 탭 한가운데, 화면 폭의 약 55%(220dp) 크기로 혼자 놓인다. 사용자는 목탁을 손가락으로 계속 두드린다.
- 두드리면 앱이 몸통을 살짝 눌렀다 놓고, 채를 내리쳤다 들어 올리며, 둘레로 파문이 퍼진다. **그림은 멈춘 한 장씩이면 된다.** 움직임은 앱이 만든다.
- 배경은 두 가지다. 둘 다에서 윤곽이 또렷해야 한다.
  - 밝은 화면: 아이보리 `#F5EFE3`
  - 어두운 화면: 거의 검정 `#15130F`

## 2. 화풍 — 부처님과 같은 세계

`Imgs/base_saffron.png`(내 부처님)를 첨부해 같은 화풍으로 그린다.

- 부드러운 3D, 매끈하고 둥글둥글한 형태, 과한 디테일 없이. 장난감 같은 귀여움.
- 조명은 정면 약간 **왼쪽 위**에서 오는 부드러운 빛 하나. 오른쪽 아래로 은은한 그늘.
- 칠한 나무의 은은한 광택. 나뭇결은 아주 옅게만.

## 3. 목탁 몸통 — 한국 목탁

- **한국 절의 손목탁**: 둥근 몸통 위에 손으로 쥐는 손잡이가 붙어 있다. 몸통 앞 아래쪽을 가로지르는 **가늘고 긴 틈**(울림구멍)이 있다.
- 색: 따뜻한 적갈색 나무(대추·밤색 계열). 부처님 가사의 주황(`#D98B2B`)과는 구분되게, 그보다 어둡고 붉게.
  어두운 화면에서도 묻히지 않을 만큼은 밝게.
- 각도: 정면에서 살짝 위에서 내려다본 각도. 틈이 잘 보이게. 손잡이는 몸통 뒤쪽 위로, **왼쪽 위**를 향해 비스듬히.

### 반드시 피할 것 — 얼굴처럼 보이면 안 된다

지금 코드 목탁은 틈이 웃는 입처럼 휘어 있어 처음에 「웃는 프라이팬」처럼 보였다.

- 틈은 **웃는 입처럼 크게 휘지 않는다.** 거의 곧은, 끝이 가늘어지는 좁은 틈.
- 눈처럼 보이는 점·구멍·무늬를 넣지 않는다. 몸통 위쪽은 매끈하게.
- 물고기 비늘·눈 같은 장식(중국·일본 목어 장식)을 넣지 않는다.

## 4. 목탁채

- 짧고 곧은 나무 막대 끝에 **둥근 머리**가 달린 채. 몸통과 같은 나무, 같은 색 계열에 조금 더 밝게.
- 각도: 대각선. **둥근 머리는 왼쪽 아래, 손으로 쥐는 끝은 오른쪽 위.** 앱이 쥐는 끝을 축으로 돌려 내리친다.
- 길이는 몸통 지름의 약 1.2배로 그려 준다. 크기는 앱에서 맞추므로 대략이면 된다.

## 5. 출력 (두 장 공통)

- 정사각형, 물건이 가운데, 사방에 여백 10% 이상. 어디도 잘리지 않게.
- 배경은 **투명(알파 채널)**. 안 되면 순수 마젠타 `#FF00FF`. 회색 체크무늬를 그려 넣는 건 투명이 아니다.
- 그림자·바닥·글자·워터마크·테두리 없이. 바닥 그림자는 앱이 그린다.
- 반투명 부분 없이 불투명하게.

## 6. 받고 바로 볼 것

| 보이는 것 | 할 일 |
|---|---|
| 틈과 무늬가 얼굴(눈·웃는 입)처럼 읽힌다 | 다시 요청. 가장 중요한 기준이다 |
| 중국·일본식 물고기 모양 목어다 | 다시 요청. 둥근 한국 손목탁이어야 한다 |
| 아이보리·검정 배경 중 한쪽에서 윤곽이 묻힌다 | 다시 요청 (색을 밝게/어둡게) |
| 채의 머리가 오른쪽 위에 있다 | 다시 요청. 머리는 왼쪽 아래 |
| 부처님과 화풍이 다르다 (사실적 사진풍, 납작한 일러스트) | 다시 요청 |
