# 부처님 아이템 컨셉

꾸미기 아이템을 무엇으로 채울지 정하는 문서. 이미지를 어떻게 받아 앱에 넣는지는 [부처님_리소스_파이프라인.md](부처님_리소스_파이프라인.md)를 본다.

> 2026-09-30 초안. 공덕 값은 가설이다. 수행 한 번에 쌓이는 공덕이 정해지면 다시 맞춘다.

## 방향 — 힙한 부처님

**부처님은 차분한 그대로, 차림새만 요즘 것.**

힙함은 전통과 요즘 물건이 어긋나는 데서 나온다. 돌부처가 동그란 선글라스를 끼고, 황금부처가 비니를 쓴다. 부처님이 웃기려고 애쓰는 게 아니라, 원래대로 고요한데 차림만 엉뚱해서 피식하게 만든다.

- 표정·자세는 바꾸지 않는다. 감은 눈, 옅은 미소, 합장.
- 아이템은 자기 색을 지킨다. 부처 재질이 바뀌어도 모자·소품은 그대로다. 그 대비가 곧 재미다.
- 조합이 곧 개성이다. 슬롯을 잘게 나눠 여러 개를 동시에 걸칠 수 있게 한다.

### 넣지 않는 것

앱은 불교를 몰라도 들어오게 하되, 불교를 가볍게 다루지는 않는다(PRD — 「왜곡 없는 의역」). 아래는 아이템 후보에서 뺀다.

| 넣지 않는 것 | 이유 |
|---|---|
| 술, 담배, 돈다발, 도박 | 계율과 정면으로 부딪친다 |
| 총·칼 등 무기 | 불살생 |
| 성적인 코드, 노출 | |
| 실존 브랜드 로고·줄무늬(삼선 등) | 상표 문제 |
| 다른 종교의 상징 | |
| 불상 훼손을 떠올리게 하는 것 (금 간 얼굴, 잘린 목 등) | |
| 부처님 표정을 바꾸는 것 (윙크, 혀 내밀기, 찡그림) | 고요함이 이 캐릭터의 중심이다 |

애매하면 "절 앞 기념품 가게에 있어도 스님이 웃고 넘어갈까"로 판단한다.

## 슬롯 구조

그리는 순서는 [avatar_equip.dart](../lib/features/avatar/avatar_equip.dart)의 `AvatarSlot` 순서다.

| 슬롯 | 상태 | 받는 방식 | 비워 둘 수 있나 |
|---|---|---|---|
| **부처** `buddha` | ✅ 있음 | 그림 없음. 살에 재질 색을 입힌다 | 아니오 (살빛이 기본) |
| 후광 `halo` | ✅ 있음 | 물건만 | 예 |
| 대좌 `seat` | ✅ 있음 | 물건만 | 예 |
| 가사 `robe` | ✅ 있음 | 몸 전체를 색만 바꿔 받는다 | 아니오 |
| 발 `feet` | ✅ 있음 | 물건만 (신발이 발을 다 덮게) | 예 |
| 머리 `head` | ✅ 있음 | 모자 쓴 얼굴 | 아니오 (민머리가 기본) |
| **얼굴** `face` | ✅ 있음 (악세서리에서 나눔) | 물건만 | 예 |
| **목** `neck` | ✅ 있음 (악세서리에서 나눔) | 물건만 | 예 |
| **입** `mouth` | ✅ 있음 | 물건만 | 예 |
| 손 `hand` | ⏸ 보류 | — | — |
| 배경 | ⏸ 보류 | — | — |

- **발**: 발은 가사 밑단 아래로 드러나 있어서, 신발을 물건만 받아 덮을 수 있다. 신발이 발보다 조금 크게, 발가락이 비치지 않게 받는다. `AvatarSlot`에서 가사 바로 다음이다.
- **입**: 풍선껌처럼 입 앞에 오는 것. 얼굴 슬롯에 넣지 않고 따로 둔다. 얼굴 슬롯은 하나만 고를 수 있어서, 풍선껌을 얼굴에 넣으면 **핑크 선글라스 + 풍선껌**을 같이 할 수 없다. 핑꾸부처 콘셉트에서 가장 먼저 나올 조합이다. 풍선은 입에서 앞으로 부풀어 안경 아래 테나 헤드폰보다 앞에 있으므로 **맨 마지막**에 그린다: `… → 머리 → 얼굴 → 목 → 입`.
- **손**: 지금 부처님은 합장하고 있어서 손에 물건을 쥘 수가 없다. 아이스 아메리카노나 엎어 둔 폰을 들리려면 합장하지 않은 몸 그림을 새로 받아야 하고, 그러면 가사 4종·살 레이어·머리 정합까지 전부 다시 해야 한다. 포즈를 늘리는 결정과 함께 한다.
- **배경**: 꾸미기가 아니라 무대에 가깝다. 공유 카드를 만들 때 같이 정한다.

풍선껌은 **움직이는 아이템**이다. 그림 두 장(`mouth_bubblegum` 풍선, `mouth_bubblegum_popped` 터져 입에 붙은 껌)으로 한 아이템을 만든다.

```
부풀기 (풍선을 입 중심으로 작게 → 크게, 약 2초)
  → 터짐 (한순간 살짝 더 커지며 사라짐, 0.1초)
  → 붙음 (붙은 껌이 나타나 2초 머묾)
  → 빨아들임 (붙은 껌이 입 쪽으로 작아지며 사라짐)
  → 쉬었다가 반복
```

- 크기 변화는 그림을 여러 장 받지 않고 앱에서 한 장을 키웠다 줄인다. 여러 장을 받으면 GPT가 장마다 모양을 다르게 그려 깜빡인다.
- 키우고 줄이는 기준점은 입 `(510, 396)`이다. 레이어 사각형은 다른 레이어와 같고, 그 안에서 입을 중심으로 크기만 바뀌므로 정렬 규칙(레이어별 위치 보정 금지)을 깨지 않는다.
- 옷장 썸네일과 정지 화면(공유 카드, 「동작 줄이기」 설정)은 다 부푼 풍선 한 장이다.

## 물건만 받는 GPT 프롬프트 (얼굴·목·발)

**한 아이템에 대화 하나.** 첨부로 캐릭터를 주면 크기·각도를 맞추기 쉽다.

> **첨부: `Imgs/base_saffron.png`**

```
첨부한 캐릭터에게 {아이템}을 씌우려고 합니다. {아이템}만 따로 그려 주세요.
{아이템} = {설명}

[물건]
1. {아이템} 하나만. 캐릭터의 얼굴·몸·손은 그리지 마세요.
2. 첨부 캐릭터가 실제로 {착용 위치}에 걸쳤을 때의 크기·각도로 그려 주세요.
   정면에서 본 모습입니다.
3. 화풍은 첨부와 같게. 부드러운 3D 느낌, 매끈한 표면, 과한 디테일 없이.
4. 로고, 글자, 브랜드를 떠올리게 하는 무늬는 넣지 마세요.

[출력]
5. 정사각형, 물건이 가운데. 어디도 잘리지 않게 여백을 두세요.
6. 배경은 투명(알파 채널). 안 되면 순수 마젠타(#FF00FF).
   회색 체크무늬를 그려 넣는 건 투명이 아닙니다.
7. 조명은 첨부처럼 정면 약간 왼쪽 위에서 오는 부드러운 빛 하나.
8. 그림자, 배경 장식, 테두리 없이.
```

| 슬롯 | `{착용 위치}` |
|---|---|
| 얼굴 | 눈 위 (안경처럼) / 콧등 |
| 목 | 목과 가슴 |
| 발 | 두 발 |
| 입 | 입술 앞 (입에서 불어 낸 풍선) |

받은 그림은 `Imgs/`에 물건 원본 그대로 넣고, 파이프라인 문서 「새 얼굴 · 목 · 대좌 · 후광 아이템 넣기」의 `PLACED`로 1024 캔버스 제자리에 배치한다. (`assemble_buddha_sprites.py`는 예전 방식이다.)
