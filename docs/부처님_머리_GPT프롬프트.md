> 지금 방식은 [부처님_리소스_파이프라인.md](부처님_리소스_파이프라인.md) · [부처님_머리_얼굴_GPT프롬프트.md](부처님_머리_얼굴_GPT프롬프트.md).

아이템 하나에 **대화 하나**를 쓰세요. 한 대화에서 여러 개를 시키면 앞의 것에
끌려가 화풍이 섞입니다.

아래 프롬프트에서 **`{아이템}`** 과 **`{설명}`** 만 바꿔 쓰면 됩니다.

| 아이템 | 설명 |
|---|---|
| 나발 | 부처의 곱슬 머리. 짙은 갈색 소라 모양 돌기가 머리를 촘촘히 덮고, 정수리에 볼록한 육계(살상투)가 솟아 있다 |
| 삿갓 | 넓은 원뿔 모양의 대나무 갓. 옅은 황토색, 결이 엮인 질감 |
| 밀짚모자 | 낮고 둥근 크라운에 챙이 둥글게 말린 밀짚모자. 밀짚색 바탕에 붉은 띠 |

## 1단계 — 전신 (캐릭터에 씌울 그림)

> **첨부: `base_saffron.png`**

```
첨부한 이미지를 편집해 주세요. 새로 그리지 말고, 이 이미지를 그대로 두고
머리 부분만 고쳐 주세요.

[해야 할 것]
이 부처님 캐릭터가 {아이템}을 쓴 모습으로 만들어 주세요.
{아이템} = {설명}

[반드시 지킬 것]
1. 머리 위쪽만 수정하세요. 목 아래(가사, 팔, 손, 발)는 원본 픽셀 그대로
   두세요. 지우지도 말고 다시 그리지도 마세요.
2. 얼굴은 건드리지 마세요. 눈, 입, 볼의 홍조, 귀 모양, 피부색 전부 원본
   그대로입니다. 머리에 쓰는 것만 추가합니다.
3. 이마가 보여야 합니다. {아이템}을 눈썹까지 내려 씌우지 마세요.
   이마와, 이마 한가운데 있는 작은 주황색 점(백호)이 가려지면 안 됩니다.
4. 크기는 머리에 어울리게. 챙이 머리통보다 조금 넓은 정도면 충분합니다.
   얼굴이 묻힐 만큼 크게 만들지 마세요.
5. {아이템}의 맨 윗부분이 이미지 위쪽 가장자리에 닿으면 안 됩니다.
   최소 40픽셀 이상 여백을 두세요.
6. 캐릭터의 위치와 크기가 원본과 완전히 같아야 합니다. 1픽셀도 움직이면
   안 됩니다.
7. 출력은 1024x1024, 배경은 투명(알파 채널)으로 주세요.
   투명 배경이 안 되면 순수 마젠타(#FF00FF) 배경으로 주세요.
   회색 체크무늬를 그려 넣는 건 투명이 아닙니다. 그러지 마세요.
8. 그림자, 글자, 워터마크, 테두리를 넣지 마세요.
   조명은 원본과 같이 정면 약간 왼쪽 위에서 오는 부드러운 빛 하나입니다.

[확인]
만들기 전에, 위 조건대로 이미지의 특정 영역만 편집하는 게 가능한지
알려 주세요. 전체를 새로 그리는 방식밖에 안 된다면, 그리지 말고 먼저
그렇다고 말해 주세요.
```

## 2단계 — 단독 (옷장 목록에 쓸 그림)

1단계 결과를 받은 **같은 대화에 이어서** 보내세요. 방금 만든 것과 같은 물건이
나와야 합니다.

```
방금 씌운 {아이템}만 따로 그려 주세요.

1. {아이템} 하나만 있어야 합니다. 얼굴, 머리, 몸이 들어가면 안 됩니다.
2. 방금 만든 것과 같은 물건으로 보여야 합니다. 같은 색, 같은 질감,
   같은 각도(정면에서 살짝 위에서 내려다본 각도)로 그려 주세요.
3. 배경은 투명(알파 채널). 안 되면 순수 마젠타(#FF00FF).
4. 정사각형 이미지, 물건이 가운데 오게. 크기는 적당히 하시면 됩니다.
5. 그림자, 글자, 배경 장식을 넣지 마세요.
```

## 받고 나서 바로 확인할 것

전신 3장은 **원본과 겹쳐 보면** 금방 압니다.

- 몸·팔·발이 어긋나 보이면 → 위치가 틀린 것. 다시 요청
- 얼굴이 미묘하게 달라 보이면 → 마스크 편집이 아니라 새로 그린 것. 다시 요청
- 이마나 백호가 안 보이면 → 모자가 너무 낮거나 큰 것. 다시 요청

단독 3장은 얼굴이 섞여 있지 않은지만 보면 됩니다.
