# 「명상」 버튼 아이콘 발주서

절 탭 아래 [명상] 버튼의 글자 왼쪽에 작은 그림 하나를 둔다. 「부처님 말씀」 카드의 연꽃(`Imgs/icon_lotus.png`)과 같은 방식이다. 버튼 안 글자 왼쪽, 약 24dp.

버튼 바탕은 사프란 주황 `#D98B2B`, 글자는 먹색이다. 그림은 이 주황 위에 놓인다.

## 왜 향인가

| 후보 | 좋은 점 | 걸리는 점 |
|---|---|---|
| **향 한 대와 피어오르는 연기 (추천)** | 절에서 앉아 마음을 가라앉히는 장면을 바로 떠올리게 한다. 가늘게 올라가는 연기가 「고요히 머문다」는 느낌을 준다. 다른 탭과 겹치지 않는다 | 연기가 얇으면 24dp에서 사라진다. 연기를 굵고 단순하게 그려야 한다 |
| 좌선하는 사람 실루엣 | 「명상」을 글자 그대로 보여 준다 | 바로 위에 부처님이 앉아 있어 같은 그림이 두 번 나온다 |
| 좌복(명상 방석) | 앉는 자리라 뜻이 맞다 | 작게 줄이면 그냥 쿠션이나 빵처럼 보인다 |
| 싱잉볼 | 명상과 잘 어울린다 | 놀이 탭 싱잉볼과 겹쳐 놀이로 가는 버튼처럼 읽힌다 |
| 연꽃 | 이미 있는 그림이라 비용이 없다 | 바로 위 「부처님 말씀」 카드와 같은 그림이 되어 두 요소가 구분되지 않는다 |

## 받을 것

| 저장 파일 | 내용 |
|---|---|
| `Imgs/icon_meditation.png` | 작은 향꽂이에 꽂힌 향 한 대와 위로 휘어 오르는 연기 한 줄기 |

같은 이름이 이미 있으면 덮어쓰지 말고 `_v2`처럼 번호를 붙인다.

## 그림 조건

- **화풍**: `Imgs/base_saffron.png`(부처님), `Imgs/icon_lotus.png`(연꽃 아이콘)와 같은 세계. 부드러운 3D, 매끈하고 둥근 형태, 과한 디테일 없이.
- **구성**: 아래에 낮고 둥근 향꽂이(진한 갈색 또는 청동색), 가운데 곧은 향 한 대(짙은 적갈색), 향 끝에 작은 불씨, 그 위로 S자로 한두 번 휘는 연기 한 줄기.
- **연기**: 흰색에 가까운 연한 회백색. **굵고 매끈한 띠 모양**으로, 끝으로 갈수록 가늘어지되 끊기지 않게. 24dp로 줄여도 보여야 한다.
- **조명**: 왼쪽 위에서 오는 부드러운 빛 하나.
- **배경**: 주황 버튼 `#D98B2B` 위에 놓인다. 향꽂이·향은 주황보다 충분히 어둡고, 연기는 주황보다 충분히 밝아야 한다. 주황·노랑 계열 색은 쓰지 않는다(불씨의 작은 점만 예외).

### 피할 것

- 글자, 만(卍) 같은 기호, 부처님이나 사람
- 반짝이, 빛줄기, 후광 같은 장식
- 여러 대의 향, 향로 가득한 재, 제단·초 같은 배경
- 그림자, 테두리
- 제사·장례를 떠올리게 하는 큰 향로나 국화

## 출력

- 정사각형 1024×1024, 그림이 가운데, 사방에 여백 10% 이상. 연기까지 포함해 세로로 긴 그림이 되어도 된다.
- 배경은 **투명(알파 채널)**. 안 되면 순수 마젠타 `#FF00FF`. 회색 체크무늬를 그려 넣는 건 투명이 아니다.
- 연기 가장자리 말고는 반투명 없이 불투명하게.
