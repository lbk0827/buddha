# 부처핸섬 — 현재 방향과 개발 현황

> 2026-10-05 기준. 기획자와 다음 방향을 정하기 위한 정리다.
> 코드가 기획 문서보다 앞서 나간 부분이 있어서, **지금 앱이 실제로 어떤지**를 먼저 적고
> 기획서와 다른 점, 정해야 할 것을 뒤에 둔다.

## 한 줄

**내 부처님을 꾸미고, 목탁·싱잉볼·번뇌 태우기로 잠깐 쉬어 가는 작은 절.**
쉬면서 모은 공덕으로 부처님 옷을 연다.

기획서 v3(2026-09-24)의 「불교를 몰라도 웃으며 들어와, 내 마음을 알아차리고, 조금
가벼워져 나가는 내 손안의 작은 절」에서 출발했지만, 화면의 주인공은 「폰 엎기 수행」에서
「꾸미는 부처님 캐릭터와 놀이」로 옮겨 왔다.

## 2. 지금 앱 구성

하단 HUD 다섯 탭. 상단 바에는 공덕 알약과 증표·프로필 버튼.

| 탭 | 보이는 것 | 하는 일 |
|---|---|---|
| **절** (홈) | 가운데 큰 부처님, 아래 「부처님의 한마디」 카드, 하단 **[마음 비우기]** | 부처님을 누르면 꾸미기, 카드를 누르면 선사 탭, 버튼은 폰 엎기(3분·10분) |
| **꾸미기** | 부처님 미리보기 + 슬롯별 아이템 | 공덕으로 아이템을 열고 입힌다 |
| **놀이** | 목탁 또는 싱잉볼 하나, 아래 「번뇌 태우기」 카드 | 두드리고, 치고, 문지른다. 염주가 넘어가고 공덕이 쌓인다 |
| **선사** | 오늘의 한마디 1개, 공유·「피식」 | 「번뇌 한 줄 적기」로 태우기에 들어간다 |
| **소원** | 연등 다섯 개, 아래 「내가 단 소원 N개」, 하단 **[소원 빌기]** | 연등을 누르면 소원을 읽고, 버튼으로 소원을 적어 단다(기기에만 저장) |

**증표**는 탭이 아니다(2026-10-06). 상단 바의 증표 버튼이나 설정에서 연다. 증표 그리드(전체 / 해제됨 / 시즌), 조건을 채우면 열린다. 실물 굿즈·구매는 없다.

처음 켜면 **가상 출가**로 법명을 하나 받고 시작한다(셀카는 없음).

### 놀이

- **목탁** — 탭하면 채가 내리치고 「톡」 소리, 진동, 파문.
- **싱잉볼** — 탭하면 친다. 테두리를 손가락으로 빙글빙글 돌리면 울림이 차오르고 테두리가 빛난다.
- **번뇌 태우기** — 한 줄 적기 → 선사의 죽비 한마디 → 「인정. 태운다」 또는 「반박」 → 연등에 매단 쪽지가 탄다.
  위기 신호가 감지되면 선사 대사 없이 평문 안내로 보낸다.

### 꾸미기

- 슬롯 9개: 부처(재질) · 후광 · 대좌 · 가사 · 발 · 머리 · 얼굴 · 목 · 입. 아이템 27개, 공덕으로 여는 것 24개(합계 17,850).
- 그림은 3D 렌더 PNG를 겹치는 레이어 방식. 새 아이템 넣는 절차는 [부처님_리소스_파이프라인.md](부처님_리소스_파이프라인.md), 콘셉트는 [부처님_아이템_컨셉.md](부처님_아이템_컨셉.md).
- 풍선껌처럼 움직이는 아이템도 된다.

## 3. 공덕 경제

공덕은 옷장을 여는 재화다. 폰 엎기를 뺐던 동안 수입원이 번뇌 태우기 하나만 남아,
2026-10-05에 놀이 탭에서 벌 수 있게 바꿨다.

| 얻는 곳 | 얼마 | 하루 상한 |
|---|---|---|
| 놀이 — 염주 한 바퀴 | 108알 = **20** | 5바퀴 (100) |
| 번뇌 태우기 | 1개 = **15** | 3개 (45) |
| 폰 엎기 | 엎어둔 1분 = **10** | 없음 (3·10분 세션이라 저절로 제한된다) |

- **염주 한 알** = 목탁 한 번, 싱잉볼 한 번 치기, 싱잉볼이 울리는 0.5초. 한 바퀴는 1분 남짓.
- **상한을 넘겨도 막지 않는다.** 두드리기와 태우기는 그대로 되고, 바퀴 수와 태운 개수도 센다. 공덕만 멈춘다.
  기획서 v3의 「반복이 최적 성장법이 되지 않게, 처벌 없이」를 따랐다.
- 놀이·태우기만으로는 하루 최대 145. 가장 싼 아이템(150)은 첫날이나 이튿날, 옷장 전부는 넉 달쯤.
- 폰 엎기는 상한이 없다(원래 기획 그대로). 10분 세션을 거듭하면 한 시간에 600까지 벌 수 있어 놀이보다 훨씬 크다. 상한을 둘지 정해야 한다.
- 숫자는 전부 가설값이다. 실제 사용 패턴을 보고 조정한다.

## 4. 개발된 것

### 쓰이고 있는 것

| 영역 | 내용 |
|---|---|
| 셸 | 하단 HUD 다섯 탭, 탭마다 같은 상단 바(공덕·프로필) |
| 부처님 | 레이어 합성, 꾸미기 9슬롯, 공덕으로 구매, 착용 저장 |
| 놀이 | 목탁·싱잉볼 그림·소리·채 연출, 싱잉볼 문지르기, 염주·공덕 |
| 번뇌 태우기 | 쓰기 → 죽비 → 인정/반박 → 태우기 연출, 위기 신호 분기 |
| 선사 | 오늘의 한마디(하루 1개, 14일 반복 제한), 공유 카드, 「피식」 |
| 증표 | 6종, 해제 조건 계산, 다음에 가까운 증표 |
| 가상 출가 | 법명 후보 10개 중 하나, 뜻 한 줄 |
| 유형 테스트 | 「내 마음의 보살 찾기」 16문항 + 심화, 요소별 비율 채점, 대표·경향·혼합·유보 4등급, 3층 결과. 프로필에서 들어간다 |
| 기록·설정 | 기록 화면, 알림 동의, 기록 저장 동의, 숫자 가리기, 데이터 전체 삭제 |
| 안전 | 위기 키워드 감지와 평문 안내 화면 |
| 알림 | 동의 후 다음 날 1회 재방문 알림 |

### 만들었지만 들어가는 길이 없는 화면

화면과 라우트는 있지만, **앱 안에 그 화면으로 가는 버튼이 없다.** 사용자는 볼 수 없다.

| 화면 | 원래 자리 | 지금 |
|---|---|---|
| **말씀의 뿌리** (한마디 → 쉬운 해설 → 근거 말씀 3단) | 기획서 v3에서 「이게 없으면 부처핸섬이 아니다」라고 한 핵심. 한마디 카드 아래 [이 말의 뿌리] | 링크 없음. 콘텐츠도 9건 전부 초안이라 켜도 안 보인다(5건 공개 필요) |
| **절 마당** (인정일로 등·나무·돌담·종·법당·일주문) | 첫 화면의 배경 | 홈이 부처님으로 바뀌며 빠짐 |
| **오늘의 체크인** | 유형 테스트 옆 짧은 버전 | 링크 없음 |

### 폰 엎기 — 2026-10-05 되살림

- 절 탭 하단 [마음 비우기] → 설정(3분·10분, 번뇌 한 줄) → [엎었다] → 검은 화면 → 종료(「+N 공덕」).
- 이것에 기대던 법명 진화, 증표 「첫 엎기」「엎기 100회」「무결」, 인정일·절 단계가 다시 채워진다.
- 남은 약점: 버튼을 누르고 다른 앱을 쓰다 돌아와도 완주로 센다(센서 미검증). 3분 동안 화면이 비어 있다.

**참고 — 「108배」는 폰을 108번 엎는 게 아니다.** 3분이나 10분 동안 폰을 엎어 두는 세션 한 번이
1배로, 날마다 쌓여 108이 된다. 센서도 쓰지 않는다(센서 감지는 플래그로 꺼져 있고 [엎었다] 버튼으로
시작한다). 기기에 무리가 갈 일은 없다.

## 5. 기획서 v3와 다른 점

| 기획서 v3 | 지금 앱 |
|---|---|
| 첫 화면 세 입구: 마음 내려놓기(대표) · 오늘의 한마디 · 내 마음 알아보기 | 부처님 캐릭터 + 한마디 카드 + [마음 내려놓기]. 테스트는 프로필 안 |
| 핵심 성장 = 인정일 → 절 마당이 자람 | 핵심 재화 = 공덕 → 부처님 옷. 절 마당은 화면에 없음 |
| 말씀의 뿌리가 정체성 | 뿌리 화면은 있으나 연결·콘텐츠 없음 |
| 선사 한마디 → [3분 내려놓기] [이 말의 뿌리] | 한마디 → 공유·피식, 번뇌 한 줄 적기 |
| 번뇌 한 줄은 수행 앞 단계 | 번뇌 태우기는 독립 놀이 |
| 굿즈(단주) 수요 검증 | 실물 굿즈 없음. 증표가 그 자리 |

그대로 지키는 원칙: 강요 없음, 처벌 없음(차감·쿨다운 없음), 무음 오디오 없음,
화면 시간을 보상 조건으로 쓰지 않음, 위기 신호 시 유머 끄고 평문 안내, 모든 기록은 기기 안에.

## 6. 정해야 할 것

| # | 질문 | 선택지 | 영향 |
|---|---|---|---|
| 1 | **폰 엎기**를 어떻게 다듬을까 (10/5 원래 형태로 되살림) | 그대로 / 싱잉볼로 시작·끝 알림 / 센서 감지 | 지금은 다른 앱을 쓰다 와도 완주로 센다. 빈 3분을 채울지도 정할 것 |
| 2 | **법명 진화**를 엎기만으로 올릴까 | 엎기 횟수(지금) / 염주 바퀴·태운 번뇌도 함께 | 염주 누적 바퀴(`beadRounds`)는 이미 저장하고 있다 |
| 3 | **증표**에 놀이 증표를 더할까 | 「첫 바퀴」「염주 100바퀴」 등 | 엎기 증표 3종은 다시 열 수 있게 됐다 |
| 4 | **말씀의 뿌리**를 살릴까 | 한마디 카드에 링크 + 감수 / 뒤로 미룸 | 살리려면 스님 감수로 5건 이상 공개가 필요 |
| 5 | **절 마당**을 살릴까 | 홈 배경으로 / 별도 화면 / 뺌 | 인정일과 함께 정할 문제 |
| 6 | 공덕 숫자 | 지금 값 유지 / 조정 | 실제 사용 후 |
| 7 | 기준 문서 | 이 문서를 바탕으로 기획서 v4 | PRD·기획서 v3는 지금 앱과 다르다 |

출시 전에 따로 필요한 것: 위기 키워드·연락처 전문가 검수, 선사 대사·뿌리 콘텐츠 감수, 실기기 테스트.

## 7. 기술 현황

| 항목 | 내용 |
|---|---|
| 프레임워크 | Flutter, Riverpod, go_router |
| 저장 | drift(SQLite), 스키마 4. 서버 없음, 전부 기기 안 |
| 소리 | audioplayers. 목탁 CC0 녹음, 싱잉볼 직접 합성. 출처는 [사운드_출처.md](사운드_출처.md) |

| 콘텐츠 | `assets/content/` — 선사 대사 117, 유형 테스트 문항, 뿌리 9(전부 초안), 위기 안내 |
| 테스트 | 290개 통과, 정적 분석 이슈 0 (2026-10-05) |
