# 부처님 머리 아이템 재작업 의뢰서

> **⚠ 지난 방식 — 이 문서대로 받지 마세요.**
> 베이스 전신을 편집해 받는 방식이었는데, 실제로는 「모자 쓴 얼굴」만 받아 눈·귀로 맞추는 방식으로 자리 잡았다.
> 지금 방식은 [부처님_리소스_파이프라인.md](부처님_리소스_파이프라인.md) · [부처님_머리_얼굴_GPT프롬프트.md](부처님_머리_얼굴_GPT프롬프트.md).

머리 아이템 3종(나발·삿갓·밀짚모자)을 다시 만듭니다.
**나머지 8장(베이스 4, 악세서리 2, 대좌, 후광)은 문제없으니 건드리지 마세요.**

---

## 1. 무엇이 잘못됐나

지난번에 **"모자만 남기고 나머지는 투명하게"** 라고 요청드렸습니다. 그게 잘못이었습니다.

모자를 독립된 물건으로 그리면 **그 모자가 이 캐릭터의 머리에 맞는지 알 수가 없습니다.**
받은 삿갓·밀짚모자를 얹어 보니

- 캐릭터의 눈이 세로 290 지점에 있는데 **모자 챙 아래가 278** 이라, 눈썹 바로 위에서 잘려 **이마가 통째로 사라졌습니다.** 이마 중앙의 백호도 가려집니다
- 위로 올려 고치려 했지만 **삿갓이 캔버스 맨 위(세로 8)부터** 그려져 있어 여유가 8픽셀뿐입니다. 올리면 꼭대기가 잘립니다
- 모자 자체도 머리보다 훨씬 큽니다

**모자를 머리에 씌운 채로 그려야 합니다.**

## 2. 이번엔 아이템마다 2장씩 받습니다

용도가 다른 두 그림이 필요합니다.

| 종류 | 파일명 | 쓰임 | 요구사항 |
|---|---|---|---|
| **전신** | `head_삿갓_full.png` | 캐릭터에 씌울 그림 | 위치가 원본과 정확히 같아야 함 |
| **단독** | `head_삿갓_item.png` | 옷장 목록에 보여줄 그림 | 위치 자유, 물건만 |

전신 그림에서는 제가 **목 위만 잘라내서** 씁니다. 그러니 목 아래를 지우려 애쓰지 마세요.
원본 그대로 두시는 게 오히려 좋습니다.

단독 그림은 옷장 칸에 들어갑니다. 얼굴이 같이 나오면 목록이 답답해서, **물건만** 필요합니다.

## 3. 전신 그림 (3장) — 위치가 생명

### 만드는 법

`base_saffron.png`(함께 전달)를 **입력 이미지로 넣고, 머리 부분만 마스킹해서 편집**해 주세요.

1. `base_saffron.png` 를 엽니다
2. **머리 부분만** 마스크로 선택합니다 (목 아래는 선택하지 않습니다)
3. 그 안에 "이 부처님이 OOO을 쓴 모습"을 그리게 합니다
4. **목 아래는 원본 그대로 둡니다.** 지우지 마세요

마스크 밖이 보존되므로 캐릭터 위치·얼굴·피부색·가사가 그대로 유지됩니다.

> **처음부터 새로 그리지 마세요.** 새로 그리면 머리 크기와 위치가 달라져 몸과 안 맞습니다.
> 마스크 편집이 안 되면 그리기 전에 먼저 알려 주세요. 방식을 바꿔야 합니다.

### 지켜야 할 것

1. **캔버스 1024 × 1024**, 배경 투명. 안 되면 `#FF00FF`
2. **캐릭터가 1픽셀도 움직이면 안 됩니다.** 원본과 겹쳤을 때 몸·팔·발이 정확히 포개져야 합니다
3. **얼굴은 원본 그대로.** 눈·입·볼 홍조·귀 모양·피부색을 바꾸지 마세요. 머리에 씌우는 것만 더합니다
4. **이마가 보여야 합니다.** 모자를 눈썹까지 내려 씌우지 마세요. **이마와 백호(이마 중앙 주황 점)가 드러나야 합니다**
5. **모자 크기는 머리에 어울리게.** 챙이 머리통보다 약간 넓은 정도면 충분합니다
6. **모자 꼭대기가 캔버스 맨 위에 닿지 않게**, 최소 40픽셀 이상 띄워 주세요
7. 그림자·글자·워터마크 금지. 조명은 원본과 같이 정면 약간 왼쪽 위

### 파일

| 파일명 | 내용 |
|---|---|
| `head_nabal_full.png` | 나발을 얹은 전신. 짙은 갈색 소라 모양 돌기가 촘촘하고, 정수리에 볼록한 육계 |
| `head_bamboo_full.png` | 삿갓을 쓴 전신. 넓은 원뿔형 대나무 갓, 옅은 황토색 |
| `head_straw_full.png` | 밀짚모자를 쓴 전신. 낮은 크라운에 둥근 챙, 밀짚색에 붉은 띠 |

## 4. 단독 그림 (3장) — 위치는 자유

옷장 목록에 넣을 아이콘입니다. **전신 그림에 쓴 것과 같은 모자**를 물건만 따로 그려 주세요.

1. **물건 하나만.** 얼굴·머리·몸이 들어가면 안 됩니다
2. 배경 투명. 안 되면 `#FF00FF`
3. 정사각 캔버스, 물건이 가운데. **크기는 알아서** 하셔도 됩니다 (앱에서 맞춥니다)
4. 전신 그림과 **같은 각도·같은 색·같은 질감**. 정면에서 살짝 위에서 본 각도
5. 그림자 없음

| 파일명 | 내용 |
|---|---|
| `head_nabal_item.png` | 나발(곱슬 머리)만 |
| `head_bamboo_item.png` | 삿갓만 |
| `head_straw_item.png` | 밀짚모자만 |

## 5. 검수 기준

**전신 3장**
- [ ] 1024×1024, 배경 투명(또는 `#FF00FF`)
- [ ] `base_saffron.png` 위에 겹쳤을 때 **몸·팔·발이 정확히 포개지는가**
- [ ] **이마와 백호가 보이는가** — 모자가 눈썹까지 내려오지 않았는가
- [ ] 모자 꼭대기가 캔버스 위쪽에 닿지 않았는가 (40픽셀 이상 여유)
- [ ] 얼굴·피부색이 원본과 같은가 — 세 장을 번갈아 봤을 때 얼굴이 흔들리지 않는가

**단독 3장**
- [ ] 물건만 있고 얼굴·몸이 없는가
- [ ] 배경 투명(또는 `#FF00FF`)
- [ ] 전신 그림의 모자와 같은 물건으로 보이는가

## 6. 지난번과 달라진 점

| 지난번 (잘못) | 이번 (맞게) |
|---|---|
| 모자만 그리고 나머지 투명 | **전신**을 그리고, 목 위는 내가 잘라 쓴다 |
| 모자를 독립된 물건으로 생성 | 베이스를 입력으로 **머리 영역만 마스크 편집** |
| 머리에 맞는지 확인 못 함 | 머리에 씌운 채로 그리므로 애초에 맞음 |
| 이마를 덮을 만큼 크고 낮게 | 이마와 백호가 보이게, 머리 위에 얹히게 |
| 아이템마다 1장 | **아이템마다 2장** (캐릭터용 전신 + 옷장용 단독) |
