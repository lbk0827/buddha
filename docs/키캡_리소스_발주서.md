## 아이콘 그림 조건 (14개 공통)

- **키캡 위에 인쇄한 그림**처럼. 레퍼런스 키링의 그림과 같은 결 — 평평한 벡터 일러스트, 짙은 갈색빛 검정(`#2B2420`) 외곽선, 면은 단색에 그늘 한 단계 정도.
  3D 렌더, 사진, 광택·반사, 그라데이션 덩어리는 쓰지 않는다.
- **14개가 한 세트로 보여야 한다.** 외곽선 굵기(그림 폭의 약 3.5%), 색 진하기, 둥근 정도, 정면 시점을 모두 맞춘다.
- 색: 밝고 부드러운 원색. 주황 `#F0A040`, 노랑 `#FFD25A`, 초록 `#6CC070`, 하늘 `#7EC8E8`, 분홍 `#F49AB0`, 빨강 `#E04A3C`, 회색 `#A9A9B2`, 갈색 `#9A6A44` 계열.
- 흰색·크림·연두·핑크 키캡 네 가지 위에 모두 놓인다. **그림 자체에 외곽선이 있어** 어느 바탕에서도 형태가 읽혀야 한다. 흰 부분(구름·로켓)은 외곽선 안을 아주 연한 회백 `#F4F2EE`로 칠한다.
- **작게 봐도 읽혀야 한다.** 키캡 위에서 약 34dp(휴대폰에서 100px 남짓)로 찍힌다. 디테일 줄이고 덩어리를 크게.
- 사람·부처님 얼굴은 동글동글하고 귀엽게. 우스꽝스럽지만 공손하게 — 부처님을 깎아내리는 표정(바보스러움·화남)은 피한다.

### 피할 것 (아이콘)

- **글자·숫자·기호**(「6」「MON」「zzz」, 만(卍) 등). 시계 숫자판도 점으로만
- 키캡 모양·테두리·바탕 사각형 — 그림만. 키캡은 앱이 그린다
- 그림자, 반짝이, 빛줄기 장식
- 레퍼런스 그림을 그대로 베끼기 — 결만 따른다

### 출력 (아이콘)

- 정사각 1024×1024, 그림이 가운데, 사방 여백 10% 이상
- 배경 **투명(알파 채널)**. 안 되면 순수 마젠타 `#FF00FF`로 그려 받은 뒤 투명으로 바꾼다. 회색 체크무늬를 그려 넣는 건 투명이 아니다
- 외곽선 바깥에 반투명 번짐 없이 불투명하게

## 쇠붙이 (`keyring.png`)

레퍼런스 왼쪽 끝 은색 쇠붙이. 앱에서 키캡이 꽂힌 판의 **왼쪽 끝 구멍**에 걸린다.

- **가로로 놓인 구성**, 왼쪽에서 오른쪽으로: 큰 **둥근 열쇠고리**(이중 링, 지름이 전체 폭의 약 45%) → 거기 걸린 **랍스터 걸쇠** → 짧은 체인 2~3마디 → 오른쪽 끝 **작은 동그란 고리 하나**.
- 오른쪽 끝 작은 고리가 판 구멍에 걸리는 자리다. **이 고리는 그림 세로 가운데 높이에** 두고, 그림의 가장 오른쪽 끝이 이 고리여야 한다.
- 큰 열쇠고리는 아래로 살짝 처져도 된다(중력). 단 그림 전체가 고리 높이를 기준으로 위아래로 크게 치우치지 않게.
- 재질: 매끈한 **은색 금속**, 부드러운 3D 렌더. 왼쪽 위에서 오는 부드러운 빛 하나, 하이라이트는 은은하게. 크롬처럼 번쩍이는 반사는 피한다.
- 아이콘과 달리 이건 **3D 렌더**다. 부처님(`Imgs/base_saffron.png`)·목탁(`Imgs/moktak_body.png`)과 같은 부드러운 3D 결.
- 출력: 가로 1536×세로 1024, 배경 투명. 그림 외 그림자·바닥 없음. 쇠붙이가 가로 폭의 80% 이상을 채운다.

## 최적화

원본(`Imgs/keycap/`)은 저장소에 남는 납품본이고, 앱에는 줄인 WebP(`assets/keycap/`)만 들어간다.

| 단계 | 할 일 | 기준 |
|---|---|---|
| 원본 PNG | 완전 투명 픽셀(알파 0)의 RGB를 0으로 비우고, 무손실 압축(`optimize=True`)으로 다시 저장. 크기는 줄이지 않는다 | 아이콘 1장 600KB 이하, 쇠붙이 1.2MB 이하 |
| 앱 에셋 | `python tools/build_keycap_assets.py` — 아이콘은 그림 영역만 잘라 192×192, 쇠붙이는 높이 320, WebP 품질 90 | 아이콘 1장 12KB 이하, 쇠붙이 40KB 이하, `assets/keycap/` 합계 250KB 이하 |
| 정리 | `assets/keycap/`에 WebP 15개만 남긴다. PNG·`.gitkeep`은 지운다 | |

192px은 키캡 위 아이콘(약 34dp) × 기기 배율 4를 덮는다. 더 크게 구우면 APK만 커진다.
기준을 넘으면 그림의 잔 디테일·노이즈를 줄여 다시 만든다(품질 값을 낮추지 않는다).

1. 대조표로 검수한다. 세트에서 튀는 그림은 그 그림만 다시 요청한다.
2. Codex가 구운 `assets/keycap/` WebP의 용량과 헤일로를 확인한다. 원본을 고쳤으면 `python tools/build_keycap_assets.py`로 다시 굽는다.
