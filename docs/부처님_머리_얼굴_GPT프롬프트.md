# GPT 프롬프트 — 머리 아이템 (모자 쓴 얼굴)

머리 아이템을 새로 받을 때 쓴다. 전체 절차는 [부처님_리소스_파이프라인.md](부처님_리소스_파이프라인.md).

**한 아이템에 대화 하나.** 한 대화에서 여러 개를 시키면 앞의 것에 끌려가 화풍이 섞인다.

아래에서 **`{아이템}`** 과 **`{설명}`** 만 바꿔 쓴다.

| 아이템 | 설명 (예시) |
|---|---|
| 삿갓 | 넓은 원뿔 모양의 대나무 갓. 옅은 황토색, 결이 엮인 질감 |
| 밀짚모자 | 낮고 둥근 크라운에 챙이 둥글게 말린 밀짚모자. 밀짚색 바탕에 붉은 띠 |
| 나발 | 부처의 곱슬 머리. 짙은 갈색 소라 모양 돌기가 머리를 촘촘히 덮고, 정수리가 볼록하다 |

---

## 1. 모자 쓴 얼굴 (필수)

> **첨부: `Imgs/base_saffron.png`**

```
첨부한 캐릭터의 머리만 다시 그려 주세요. 이 캐릭터가 {아이템}을 쓴 모습입니다.
{아이템} = {설명}

[그릴 범위]
- 머리와 목 윗부분까지만. 어깨·가사·손·몸은 그리지 마세요.

[얼굴 — 첨부 캐릭터와 똑같이]
1. 눈은 감은 모습 그대로, 새까만 가로선 두 개. 뜨게 하거나 모양을 바꾸지 마세요.
2. 눈썹, 입, 볼 홍조, 피부색, 머리 비율을 첨부와 같게 그려 주세요.
3. 귀는 크게 늘어진 모양 그대로, 양쪽 귀가 끝까지 다 보여야 합니다.
   {아이템}이 귀를 덮으면 안 됩니다.

[{아이템}]
4. 머리에 실제로 씌운 모습이어야 합니다. 머리 위에 얹어만 둔 것처럼 보이면 안 됩니다.
5. 이마가 보여야 합니다. 눈썹 위로 이마가 드러나고, 이마 한가운데의 작은
   주황색 점(백호)이 가려지면 안 됩니다.
6. 크기는 머리에 어울리게. 챙이 머리통보다 조금 넓은 정도면 충분합니다.

[출력]
7. 정사각형 이미지, 머리가 가운데. 위아래로 여백을 두어 어디도 잘리지 않게.
8. 배경은 투명(알파 채널). 투명이 안 되면 순수 마젠타(#FF00FF) 배경.
   회색 체크무늬를 그려 넣는 건 투명이 아닙니다.
9. 정면. 조명은 첨부처럼 정면 약간 왼쪽 위에서 오는 부드러운 빛 하나.
10. 그림자, 글자, 워터마크, 테두리 없이.
```

## 2. 물건만 (선택)

썸네일에 얼굴이 섞여 나올 때만 받는다. 1번과 **같은 대화에 이어서** 보낸다.

```
방금 씌운 {아이템}만 따로 그려 주세요.

1. {아이템} 하나만. 얼굴·머리·몸이 들어가면 안 됩니다.
2. 방금 것과 같은 물건으로 보여야 합니다. 같은 색, 같은 질감, 같은 각도.
3. 배경은 투명(알파 채널). 안 되면 순수 마젠타(#FF00FF).
4. 정사각형, 물건이 가운데.
5. 그림자, 글자, 배경 장식 없이.
```
