# 꾸미기 파츠 브레인스토밍

두 단계다. 1단계 결과를 보여 주고, 사용자가 고르면 2단계로 간다.

## 0. 먼저 읽기

- `lib/features/avatar/avatar_equip.dart`의 `kWardrobe` — 이미 있는 아이템과 슬롯별 공덕 가격대
- [docs/커스터마이징_파츠_발주서.md](../../../docs/커스터마이징_파츠_발주서.md) — 이미 발주한 것, 「뺀 것」과 이유, 표 형식
- [docs/부처님_리소스_파이프라인.md](../../../docs/부처님_리소스_파이프라인.md)의 「부처 재질 — 안 되는 것」

있는 것·발주한 것·이미 뺀 것은 다시 내지 않는다. 색만 바꾼 변형은 「기존 ○○의 색 변형」이라고 밝힌다.

## 1. 아이디어 내기

슬롯별로 묶고 아이템마다 🤪(우스꽝)·😎(힙)를 붙인다. 신호등 선글라스처럼 **실루엣만 봐도 웃긴 것**, 한국 생활감(목욕탕, 붕어빵, 아줌마 파마)이 묻은 것이 반응이 좋았다.

슬롯마다 지금 파이프라인이 허락하는 것만 낸다. 안 되는 아이디어가 꼭 좋으면 따로 「어려운 것」에 이유와 함께 둔다.

| 슬롯 | 되는 것 | 안 되는 것 |
|---|---|---|
| 얼굴 | 눈 앞에 붙는 물건(안경류, 안대, 고글). 머리 위로 솟아도 됨 | 얼굴 전체를 덮는 것(입·얼굴 아이템과 겹침), 반투명 렌즈 |
| 입 | 입에 물거나 입 위에 붙는 물건 | 입술·피부가 들어간 것(재질을 입으면 살빛으로 남음), 눈까지 닿는 큰 것 |
| 목 | 목에 걸려 가슴으로 내려오는 것. 손 뒤로 지나감 | 손 앞으로 와야 의미가 있는 것 |
| 발 | 두 발을 다 덮는 한 켤레 | 발이 비치는 것(샌들 끈), 발바닥 아래로 80px 넘게 나오는 것 |
| 대좌 | 몸 뒤에 깔리는 **납작한** 것(발바닥 아래 약 100px) | 키 큰 것(의자 다리, 계단) |
| 후광 | 머리 뒤에 두는 것. 회전 같은 움직임은 따로 개발 | 머리 앞으로 와야 하는 것 |
| 머리 | 모자·머리 모양. 감은 눈, 두 귀, 백호가 다 보여야 함 | 얼굴을 덮는 헬멧, 귀를 덮는 모자, 턱끈 |
| 가사 | 실루엣은 그대로, 색·무늬·천만 바뀜 | 모양이 다른 옷(망토, 후드), 피부색과 비슷한 여러 색 무늬는 어려움 |
| 재질 | 살 밝기를 두 색 사이로 옮기는 것 | 광택 금속(크롬·은), 반짝이·결 같은 질감 |

함께 지킬 것:
- 상표·로고·실존 캐릭터·브랜드 무늬 없이.
- 불교 소재를 비웃지 않는다. 술·고기·담배, 다른 종교 상징은 내지 않는다.
- 공덕은 같은 슬롯 기존 가격대 안에서, 웃긴 것보다 공들인 힙한 것을 조금 비싸게.

보여 줄 것: 슬롯별 목록, 「어려운 것」, 그리고 **재미 대비 만들기 쉬운 것 3~5개 추천**. 두 슬롯을 엮는 세트(예: 체인+금니+스냅백)가 되면 같이 적는다. 대화로만 보여 주고 아직 문서에 쓰지 않는다.

## 2. 발주서에 적기

사용자가 고른 것을 발주서에 **새 차수**로 덧붙인다. 기존 차수 번호와 표는 바꾸지 않는다.

- 맨 위 차수 표에 줄을 더하고, 본문에 「## {N}차 — {슬롯}」 절을 만든다.
- 표 열은 같은 슬롯의 기존 차수와 똑같이: `id`, 이름, 🤪/😎, `{설명}`, `{착용}`, 자리·크기(원본에서 잴 곳 → 베이스 좌표), 숨길 곳(목·발), 공덕.
  - `{설명}`은 GPT가 그대로 그릴 수 있게 색·재질·모양까지. 분홍이 들어가면 배경을 초록으로 받는다는 규칙이 적용된다.
  - 자리·크기는 발주서 「자리·크기 기준」 좌표에서 출발해 적는다.
- 슬롯이 같은 기존 차수가 있으면 그 프롬프트를 가리키고 새로 쓰지 않는다.
- 이번에 뺀 아이디어는 「뺀 것」 표에 이유와 함께 더한다.
- id 는 `acc_`(얼굴·목), `mouth_`, `feet_`, `seat_`, `halo_`, `head_`, `robe_` 접두사에 영문 소문자.

다 쓰면 무엇을 몇 차로 넣었는지 한두 줄로 알리고, 진행은 avatar-parts 로 넘긴다.
