# 싱잉볼 이미지 작업 지시서

「놀이」 탭의 싱잉볼을 그림으로 바꾼다. 지금은 코드로 그린 임시 그릇이다(`SingingBowlPainter`).
목탁 지시서([목탁_이미지_작업지시서.md](목탁_이미지_작업지시서.md))와 같은 세계, 같은 화풍이다.

받을 것은 **두 장**이다.

| # | 저장 파일 | 내용 |
|---|---|---|
| 1 | `Imgs/singing_bowl.png` | 싱잉볼 그릇 |
| 2 | `Imgs/singing_bowl_mallet.png` | 싱잉볼 채 |

같은 이름이 이미 있으면 덮어쓰지 말고 `_v2`처럼 번호를 붙인다.

## 1. 어디에 어떻게 쓰이나

- 놀이 탭 한가운데, 목탁과 같은 자리에 화면 폭의 약 60%(240dp) 크기로 혼자 놓인다. 탭 아래 「목탁 | 싱잉볼」 전환 버튼으로 바꾼다.
- 사용자는 두 가지로 울린다.
  - **치기** — 그릇을 탭하면 앱이 채를 휘둘러 테두리를 치고, 그릇 둘레로 파문이 퍼진다.
  - **문지르기** — 손가락으로 그릇 둘레를 빙글빙글 돌리면 울림이 차오르며 **테두리가 빛난다**. 앱이 테두리 타원을 따라 빛을 그린다.
- 그래서 **그릇 입구의 타원 테두리가 또렷하게 보여야 한다.** 위에서 약간 내려다본 각도라야 안쪽이 보이고 테두리가 타원으로 읽힌다.
- **그림은 멈춘 한 장씩이면 된다.** 움직임·빛·파문은 앱이 만든다.
- 배경은 두 가지다. 둘 다에서 윤곽이 또렷해야 한다.
  - 밝은 화면: 아이보리 `#F5EFE3`
  - 어두운 화면: 거의 검정 `#15130F`

## 2. 화풍 — 부처님과 같은 세계

`Imgs/base_saffron.png`(내 부처님)를 첨부해 같은 화풍으로 그린다.

- 부드러운 3D, 매끈하고 둥글둥글한 형태, 과한 디테일 없이. 장난감 같은 귀여움.
- 조명은 정면 약간 **왼쪽 위**에서 오는 부드러운 빛 하나. 오른쪽 아래로 은은한 그늘.

## 3. 그릇

- **히말라야 싱잉볼**: 넓고 낮은 그릇. 입구가 바닥보다 넓고, 옆면이 둥글게 바닥으로 좁아진다. 다리나 받침은 없다.
- 재질: 두드려 만든 **청동·황동**. 따뜻한 금갈색에 부드러운 금속 광택. 망치 자국은 아주 옅게만.
  - 목탁(적갈색 나무)과 나란히 놓여도 구분되게, 더 밝고 노란 금속빛.
  - 어두운 화면에서도 묻히지 않을 만큼 밝게, 밝은 화면에서 노랗게 바래지 않을 만큼 깊게.
- 테두리 바로 아래와 바닥 근처에 **가는 띠 선 한두 줄**까지만. 글자·만트라·옴(ॐ) 같은 문양이나 종교 기호는 넣지 않는다.
- 각도: 정면에서 **약 25도 위에서 내려다본** 각도. 입구가 납작한 타원으로 보이고 안쪽 면이 조금 보인다.

### 반드시 피할 것

- 얼굴처럼 보이는 무늬(눈 같은 점, 웃는 입 같은 곡선). 목탁에서 한 번 겪었다.
- 그릇 안에 물·꽃·초를 넣는 것. 빈 그릇이다.
- 방석·받침·테이블. 바닥 그림자도 앱이 그린다.

## 4. 채

- 짧고 곧은 나무 막대. 한쪽 끝은 **스웨이드 가죽을 감아** 조금 두툼하다(문지르는 쪽). 다른 쪽 끝은 둥글게 다듬은 나무.
- 그릇과 어울리는 짙은 나무색, 가죽은 차분한 갈색.
- 각도: 대각선. **가죽 감은 끝은 왼쪽 아래, 손잡이 끝은 오른쪽 위.** 앱이 손잡이 끝을 축으로 돌려 친다.
- 길이는 그릇 지름의 약 0.9배로 그린다. 크기는 앱에서 맞추므로 대략이면 된다.

## 5. 출력 (두 장 공통)

- 정사각형, 물건이 가운데, 사방에 여백 10% 이상. 어디도 잘리지 않게.
- 배경은 **투명(알파 채널)**. 안 되면 순수 마젠타 `#FF00FF`. 회색 체크무늬를 그려 넣는 건 투명이 아니다.
- 그림자·바닥·글자·워터마크·테두리 없이.
- 반투명 부분 없이 불투명하게. 금속 반사도 불투명한 색으로.

## 6. 받고 바로 볼 것

| 보이는 것 | 할 일 |
|---|---|
| 정면에서 본 그릇이라 입구가 일직선이다 (타원이 안 보인다) | 다시 요청. 문지를 때 빛이 테두리를 못 따라간다 |
| 글자·만트라·종교 기호가 새겨져 있다 | 다시 요청 |
| 무늬가 얼굴(눈·입)처럼 읽힌다 | 다시 요청 |
| 목탁과 색이 비슷해 구분이 안 된다 | 다시 요청 (더 밝은 금속빛) |
| 아이보리·검정 배경 중 한쪽에서 윤곽이 묻힌다 | 다시 요청 |
| 채의 가죽 끝이 오른쪽 위에 있다 | 다시 요청. 가죽 끝은 왼쪽 아래 |
| 그릇 안에 물·꽃이 있거나 방석 위에 놓였다 | 다시 요청 |

## 받은 뒤 (Claude 작업)

1. 두 배경에 합성해 검수한다. 목탁과 나란히 놓고 색을 본다.
2. WebP로 굽는다(`assets/play/` 예정).
3. `SingingBowlPainter`를 그림 두 장으로 바꾼다. 파문·테두리 빛은 지금처럼 앱이 그리되, 받은 그릇의 입구 타원에 맞춘다.
4. 치기: 채가 손잡이 끝을 축으로 돌아 테두리를 친다. 소리(`singing_bowl_strike_v3.wav`)의 타격 시점과 맞춘다.
5. 문지르기: 손가락 위치를 따라 채가 테두리 위를 도는 모습을 넣을지, 빛만 둘지 그림을 보고 정한다.
