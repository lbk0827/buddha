## 1 · 2 — 모자 쓴 얼굴

아래 블록을 그대로 붙인다. 비니와 버킷햇은 `{아이템}`·`{설명}`만 다르다.

| `{아이템}` | `{설명}` |
|---|---|
| 비니 | 머리에 딱 붙게 쓴 니트 비니. 겨자색, 굵은 골지 짜임, 끝단을 한 번 접었다. 이마 위쪽까지만 덮는다 |
| 버킷햇 | 챙이 아래로 살짝 처진 면 버킷햇. 연한 카키색, 무늬 없음. 챙 안쪽에 머리가 보이도록 머리에 깊이 씌운다 |

```
첨부한 캐릭터의 머리만 다시 그려 주세요. 이 캐릭터가 {아이템}을 쓴 모습입니다.
{아이템} = {설명}

[가장 중요]
- 첨부 그림 위에 {아이템}을 얹지 마세요. 모자와 머리를 처음부터 함께 그려야 합니다.
  모자가 머리를 감싸 눌러 쓴 모습이어야 하고, 모자 가장자리 아래로 원래 민머리의
  윤곽선이 보이거나 모자와 머리 사이에 틈이 있으면 안 됩니다.

[그릴 범위]
- 머리와 목 윗부분까지만. 어깨·가사·손·몸은 그리지 마세요.

[얼굴 — 첨부 캐릭터와 똑같이]
1. 눈은 감은 모습 그대로, 새까만 가로선 두 개. 뜨게 하거나 모양을 바꾸지 마세요.
2. 눈썹, 입, 볼 홍조, 피부색, 머리 비율을 첨부와 같게 그려 주세요.
3. 귀는 크게 늘어진 모양 그대로, 양쪽 귀가 끝까지 다 보여야 합니다.
   {아이템}이 귀를 덮으면 안 됩니다.

[{아이템}]
4. 이마가 보여야 합니다. 눈썹 위로 이마가 드러나고, 이마 한가운데의 작은
   주황색 점(백호)이 가려지면 안 됩니다.
5. 크기는 머리에 어울리게. 머리통보다 조금 큰 정도면 충분합니다.

[출력]
6. 정사각형 이미지, 머리가 가운데. 위아래로 여백을 두어 어디도 잘리지 않게.
7. 배경은 투명(알파 채널). 투명이 안 되면 순수 마젠타(#FF00FF) 배경.
   회색 체크무늬를 그려 넣는 건 투명이 아닙니다.
8. 정면. 조명은 첨부처럼 정면 약간 왼쪽 위에서 오는 부드러운 빛 하나.
9. 그림자, 글자, 워터마크, 테두리 없이.
```

**받고 바로 볼 것**

- 모자 가장자리 바로 아래에 민머리 윤곽선이 한 줄 보이면 → 또 얹은 그림이다. 다시 요청
- 첨부 그림과 얼굴이 **완전히 똑같으면** 오히려 의심한다. 다시 그린 얼굴은 미세하게 다르다
- 눈을 떴다 / 귀가 가렸다 / 백호가 안 보인다 → 다시 요청

## 3 — 풍선껌 (물건만)

```
첨부한 캐릭터가 입으로 풍선껌을 불고 있는 장면에 쓸, 풍선껌 풍선만 따로 그려 주세요.

[물건]
1. 입에서 불어 낸 둥근 풍선껌 풍선 하나만. 캐릭터의 얼굴·입술·몸은 그리지 마세요.
2. 색은 형광 핫핑크. 매끈한 표면에 왼쪽 위로 부드러운 하이라이트 하나.
3. 풍선의 아래쪽 가운데(입에 닿는 쪽)에 껌이 조금 뭉쳐 주름진 부분이 있어,
   입에서 불어 나왔다는 게 보이게 해 주세요.
4. 정면에서 본 모습. 거의 완전한 원형, 아주 살짝만 아래로 처지게.
5. 불투명하게. 반투명으로 비치게 그리지 마세요.
6. 화풍은 첨부와 같게. 부드러운 3D 느낌, 과한 디테일 없이.

[출력]
7. 정사각형, 풍선이 가운데. 어디도 잘리지 않게 여백을 두세요.
8. 배경은 투명(알파 채널). 안 되면 순수 마젠타(#FF00FF).
   회색 체크무늬를 그려 넣는 건 투명이 아닙니다.
9. 그림자, 글자, 배경 장식, 테두리 없이.
```

**받고 바로 볼 것**

- 입술이나 얼굴이 같이 그려졌다 → 다시 요청 (입 위치는 앱에서 맞춘다)
- 반투명하게 비친다 → 다시 요청. 반투명은 레이어로 겹칠 때 결과가 예측되지 않는다

크기는 신경 쓰지 않아도 된다. 앱에서 입(1024 좌표 `(510, 396)`, 입선 폭 50px) 앞에 지름 90~110px 정도로 줄여 놓는다. 그보다 크면 안경과 턱을 다 가린다.

## 4 — 터져서 입에 붙은 껌 (물건만)

3번을 받은 **같은 대화에 이어서** 보낸다. 같은 색·같은 질감이어야 터지는 순간 바뀌어도 어색하지 않다.

```
방금 그린 풍선이 터진 직후의 모습을 그려 주세요. 터진 껌이 캐릭터의 입 둘레에
얇게 달라붙은 모습입니다. 껌만 그려 주세요.

[물건]
1. 터진 껌만. 캐릭터의 얼굴·입술·몸은 그리지 마세요.
2. 방금 풍선과 같은 형광 핫핑크, 같은 질감.
3. 입을 덮듯 가운데에 얇게 펴진 껌 한 장이 있고, 가장자리는 찢어진 듯 불규칙하게.
   양 볼 쪽으로 조금 퍼지고, 아래로 짧은 껌 가닥이 한두 개 늘어집니다.
4. 정면에서 본 모습. 얼굴에 붙어 있으니 납작하게, 입체감은 가장자리만 살짝.
5. 크기는 방금 풍선의 지름보다 조금 작게. 볼 전체나 턱 전체를 덮을 만큼 크지 않게.
6. 불투명하게. 반투명으로 비치게 그리지 마세요.

[출력]
7. 정사각형, 껌이 가운데. 어디도 잘리지 않게 여백을 두세요.
8. 배경은 투명(알파 채널). 안 되면 순수 마젠타(#FF00FF).
9. 그림자, 글자, 배경 장식, 테두리 없이.
```

**받고 바로 볼 것**

- 얼굴이나 입술이 같이 그려졌다 → 다시 요청
- 풍선과 색이 눈에 띄게 다르다 → 다시 요청
- 너무 커서 얼굴의 절반을 덮는다 → 크기는 앱에서 줄이므로 괜찮다. 다만 모양이 「얼굴 전체에 덮인 껌」이면 다시 요청

앱에서는 입 `(510, 396)`을 가운데로, 폭 110~130px 정도로 놓는다. 눈(y 356)에 닿으면 안 된다.
