# 폰 엎기

> 2026-09-29 절(Home)에서 걷어냈다가, 2026-10-05 절 탭 하단 **[마음 내려놓기]** 버튼으로 되살렸다.
> 형태는 원래대로(3분·10분). 아래 「지금 코드 상태」 참고.

## 한 줄

**폰을 엎어 둔 동안이 수행이다.** 화면을 보지 않은 시간만큼 공덕이 쌓인다.

## 흐름

```
설정 → 준비 → 수행 중 → (중단 선택 / 일시정지 → 유예) → 종료
```

| 단계 | 화면 | 내용 |
|---|---|---|
| 설정 | `session_setup_screen` | 길이 **3분 / 10분** 중 하나. 번뇌 한 줄(선택), 반복·소리 토글 |
| 준비 | `session_ready_screen` | "N분이면 된다. 엎어라. 진동 오면 시작이다." · **[엎었다]** 버튼. 60초 안에 안 누르면 취소 |
| 수행 중 | `session_running_screen` | 엎어 둔 시간만 센다. 시스템 스크린타임은 쓰지 않는다 |
| 중단 선택 | `session_interrupt_screen` | 도중에 폰을 들면 이어 할지·끝낼지 고른다. 60초 무응답이면 끝 |
| 종료 | `session_done_screen` | 수행 시간과 받은 공덕 |
| 반복 | `session_repeat_screen` | 반복을 켰으면 한 번 더 |

## 규칙 (코드에 있는 값)

| 항목 | 값 | 위치 |
|---|---|---|
| 시간 계산 | 타임스탬프 기준. 경과 − 제외 구간 합. 틱을 세지 않는다 | `session_timing.dart` `practicedSeconds()` |
| 유효 세션 | 60초 이상 | `kValidSessionSec` |
| 중단 상한 | 10분 넘게 들고 있으면 종료 | `kMaxInterruptionBeforeEnd` |
| 소리 재개 유예 | 30초 | `kAudioResumeGrace` |
| 공덕 | **1분에 10** | `session_repository.dart` `meritForSession()` |
| 중단 복구 | 앱이 죽었다 켜지면 이어서 판정 | `SessionController.restoreIfAny()` |

## 이것에 기대는 것들

폰 엎기를 빼면 아래는 **새로 채워지지 않는다.** 화면에는 남아 있지만 진척이 멈춘다.

| 기능 | 기대는 값 | 영향 |
|---|---|---|
| 법명 진화 | 엎기 횟수 — 대사 30 · 선사 108 · 조사 500 | 사미에서 멈춤 |
| 증표 「첫 엎기」 | 엎기 1회 | 못 엶 |
| 증표 「엎기 100회」 | 엎기 100회 | 못 엶 |
| 증표 「무결」 | 절 문 30일 연속 | 못 엶 |
| 절 문 | 오늘 한 번이라도 엎었는가 | 매일 닫힘 |
| 공덕 수입 | 1분에 10 | 2026-10-05부터 놀이 염주(한 바퀴 20)와 번뇌 태우기(15)가 대신한다. [현재_방향과_개발_현황.md](현재_방향과_개발_현황.md) 3절 |

다시 넣지 않을 거라면 이 여섯 가지를 다른 행동(예: 번뇌 태우기, 방문)에
옮길지 정해야 한다.

## 지금 코드 상태 (2026-10-05)

- 절 탭: 부처님의 한마디 카드 아래 **[마음 내려놓기]** 버튼과 한 줄
  (「3분이면 된다. 엎어둔 1분에 공덕 10.」 / 오늘 엎었으면 「오늘 N분 엎어뒀다.」)
- 놀이 탭이 아니라 절 탭에 둔 이유: 놀이는 화면을 보며 노는 곳이고, 폰 엎기는
  화면을 안 보는 시간이다. 절 탭 레이아웃 규칙(카드 하나 + 하단 전체 폭 버튼 하나)의
  비어 있던 버튼 자리이기도 하다
- 종료 화면에 받은 공덕(「+10 공덕」)을 보여 준다
- 위 표의 기능(법명 진화, 증표 3종, 인정일, 분당 공덕)이 다시 채워진다
- 절 문 알약은 되살리지 않았다

### 아직 남은 것

- 「엎었다」 버튼을 누르고 다른 앱을 쓰다가 시간이 지난 뒤 돌아와도 완주로 센다.
  센서 감지(방식 A·C)를 실기기에서 검증하기 전까지는 막을 수 없다
- 3분 동안 화면이 비어 있다. 싱잉볼 소리로 시작·끝을 알리는 안은 보류
